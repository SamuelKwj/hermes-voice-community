# Support

## Before Opening an Issue

Check:

1. `scripts\setup.ps1` has been executed.
2. `ffmpeg` and `ffplay` are available in PATH.
3. Hermes Gateway is running.
4. `API_SERVER_KEY` is configured correctly.
5. `/api/status` reports expected dependency and device state.

## Include This Information

- Windows version
- Python version
- Startup method
- Summary from `/api/status`
- Reproduction steps
- Expected result
- Actual result

Do not include API keys, full private logs, or private local paths.
