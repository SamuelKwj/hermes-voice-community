# Community Edition Scope

Hermes Voice Community is the Basic edition for learning, local testing, and basic Hermes Gateway integration.

## Included

- Basic desktop floating widget
- Push-to-talk recording
- Local STT
- Hermes Gateway integration
- edge-tts playback
- Basic settings and diagnostics
- Local logs

## Not Included

- Product-grade app packaging
- Release signing workflow
- Advanced floating widget experience
- Hands-free mode
- Wake word flow
- Performance profile switching
- Deep GPU optimization
- Cross-platform publishing
- Release gates

## Maintenance Principle

The community edition should stay simple, readable, and runnable.

Features that add significant product complexity, release cost, or commercial-product behavior should not be added directly to this edition.
